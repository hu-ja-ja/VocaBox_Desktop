# VocaBox

ニコニコ動画の楽曲を聴く Windows デスクトップアプリ（個人開発・実験的）。Dwango 非公式です。

動画映像は表示せず、音声中心の UI で再生します。マイリストを URL / ID で取り込み（ログイン中は自分の非公開マイリストも）、一覧から選んで再生します。
再生はアプリが取得した音声のみの HLS（ニコニコ DOMAND）を、Windows 標準のメディアスタック
（`AdaptiveMediaSource` + `MediaPlayer`）で再生する子プロセス（AmsHelper）に任せます。
表示は日本語と英語に対応し、OS の表示言語に追従します（文言は `locales/` のカタログ）。

## できること

- ホーム画面（自分のマイリストをカードで表示し、ピン留めしたものは先頭。URL から読み込んだマイリストは別枠。カードの右クリックでピン留め / 解除、読み込んだマイリストは削除）
- サイドバー（ホームと同じ並びのマイリスト。ログイン中はアカウント名とアイコンを表示し、確認ダイアログ付きでログアウト）
- マイリストの閲覧（ID または `nicovideo.jp` / `nico.ms` の URL。ログイン中は自分の非公開マイリストも）
- マイリストの保存（`%APPDATA%\VocaBox\mylists\` の索引 `index.json` と 1リスト1ファイルの本体 `{id}.json`）。ログイン後は自分の全リストを、閲覧した他人のリストはそのときに背景で保存。一覧表示は索引だけで描画し、リストを開くと本体を読み込むためオフラインでも可。更新は「更新」ボタンで手動
- 一覧はページ単位で読み込み、末尾の「続きを読み込む」で次のページを追加（保存済みのリストは本体から全体を表示）
- 結合マイリスト（保存済みのマイリストを複数選んで1本にまとめ、リストをまたいで再生。マイリストのカード / サイドバーの右クリックから作成し、ホームとサイドバーに「結合マイリスト」として並ぶ。詳細には結合元のマイリストを表示。曲はメンバーの保存内容から作り、同じ曲は1回だけ。ピン留めもでき、ピン留めするとカテゴリに関係なく先頭とレールに来る。削除しても元のマイリストは消えない）
- 再生 / 一時停止、シーク、音量、シャッフル、ループ、前へ / 次へ
- トレイ常駐とバックグラウンド再生（ウィンドウを閉じるとトレイに残り、AmsHelper が再生を続ける。トレイの左クリックで再生 / 一時停止、右クリックで再生中カードを開き、カード内で前へ / 再生 / 一時停止 / 次へ・ミュート・ウィンドウを表示・終了ができる。アイコンの色で再生中かどうかを示す。キーボードのメディアキー（再生 / 一時停止・次へ・前へ）にも対応。Windows 11 では新しいトレイアイコンは既定で「非表示のアイコン」に入るため、必要ならタスクバーの設定で表示する。二重起動はせず、2 回目の起動でウィンドウが戻る）
- シャッフルは残りの曲を一度ずつ並べ替える順列方式（再生中の曲は先頭に固定）
- 再生キュー画面（再生バー右のボタン、または再生バーの余白クリックで開閉）。再生中の曲を先頭に表示。曲の並べ替え（ドラッグ）とキューからの削除、曲名ホバーでメニュー。マイリスト画面は再生状態を表示せず、曲を再生するとキュー画面へ切り替わる
- 音質は取得可能な最高帯を自動選択（ニコニコにログインするとプレミアムの320kbpsまで。再生バーに再生中の帯を表示）
- ニコニコへのログイン（アプリ内のログイン画面でニコニコにログイン。パスワードはアプリを通らず、受け取ったセッションだけを `%APPDATA%\VocaBox\session.dat` に DPAPI 暗号化で保存）
- ウィンドウの位置・サイズを次回起動時に復元（`%APPDATA%\VocaBox\window-state.json`）。音量・シャッフル・ループも保存（`settings.json`）

## まだできないこと

- 音源ダウンロード・オフライン再生（現状のオフラインは一覧表示のみ）

## セットアップ

Windows のみ。`mise install` で Go と Rust が入ります。mise を使わない場合は Go 1.27.1 以降と `rustup toolchain install 1.97.1-x86_64-pc-windows-gnu` を用意し、`mise run` の代わりに `go tool mygo dev` などを直接実行します。

```sh
mise install     # Go と Rust（mise.toml のバージョン）
mise run dev     # AmsHelper をビルドして開発起動
mise run build   # AmsHelper をビルドして build/ に出力
mise run helper  # AmsHelper（resources/AmsHelper.exe）だけをビルド
```

## 構成

- `app/` Go（MyGo Native UI、マイリスト取得・保存、再生エンジンとキュー、ニコニコの取得、トレイ常駐）
- `helper/` Rust（AmsHelper: 再生を担う常駐ヘルパー。プロトコルは `helper/README.md`）
- `resources/` 同梱物（AmsHelper.exe。`mise run helper` の出力）

## テスト

```sh
go test ./...
VOCABOX_E2E=1 go test ./app -run TestPlaybackE2E   # 実回線/実再生の確認（数秒鳴ります）
```
