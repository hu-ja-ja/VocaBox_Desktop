# VocaBox

Windows デスクトップアプリ。公開マイリストのメタデータ表示ができます。埋め込み再生の操作部は実装済みですが、MyGo WebViewでの実際の再生・再生数への加算は未確認です。認証・ダウンロード/オフライン機能は未実装です。

再生には公式の埋め込みプレイヤーを表示し、非公式に解析された操作プロトコルで再生・一時停止・シーク・音量を送っています。一度きりのブラウザー確認では準備完了・状態変化・再生時刻の進行が見られましたが、MyGo WebViewでの再生と再生数の加算は未確認のため、何も保証しません。

## 開発起動

Go 1.27.1 以降、Bun、WebView2 Runtime が必要です。

```sh
bun install
bun run dev
```
